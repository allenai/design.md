Platform fonts
Fallback stack. EarthRanger is used in low-bandwidth field conditions where a delayed web font can mean delayed information in high-stakes moments — always pair the web font with a fast, native fallback rather than a generic one. See earthranger/DESIGN.md's Do's and Don'ts for full implementation details.
External communications typography
Not for UI. Manrope is for externally-facing communications only — slide decks, EarthRanger.com, email newsletters, and printed materials. Product interfaces always use Roboto for body text; never substitute Manrope in-app. Headings stay PP Telegraf everywhere, including external comms — only body text changes in this context.
